# ASPIRE program contract

Generate Python defining build_task(tools) and evaluate(tools, task). Return the requested action/source/summary/lesson/queries schema. Imports may use numpy, scipy, scene_geometry and the pinned upstream skill_library. Do not execute task code at module import.

Tools are a dictionary of callables: get_station_info(), get_camera_rgbd(camera), segment_camera_rgb(rgb, query), get_planning_state(), and plan_freespace_sequence(segments). Declare each perception query in the response queries array. Only top, left and right cameras exist. RGB-D includes uint8 rgb, metric depth_m, K and T_world_camera from the same capture. Derive object and finite support geometry from current observations.

World is blupe_base_midpoint, X forward/Y left/Z up at base height. Query current station calibration and arm state. ASPIRE joints are radians, API packets degrees, quaternions xyzw, jaws normalized 0 closed/1 open. Published encoder-zero POE includes model corrections already. Tool poses and native contact coordinates already use aspire_grasp; do not apply the API-to-ASPIRE rotation twice. Native X is the jaw-opening axis. Native display RPY decodes with Rotation.from_euler('xyz', [-rpy[1], rpy[0], -rpy[2]-90], degrees=True).

The bundled Robo-house profile models installed I2RT linear_4310 grippers: both positive slide joints travel 0.0475*g metres. Preserve the API grasp reference. XML/mesh hashes establish model identity, not measured physical contact calibration. Query planner_validation/native_gripper_meshes for geometry. Old opposing-slide pads and nominal pad-centroid corrections do not describe this hardware. Static station collision geometry remains nominal upstream geometry; calibration updates arm kinematics, not the complete physical box/table layout.

Return a nonempty steps list plus measured geometry required for evaluation. Each step has a unique stage. A move is {stage, kind:'move', arguments:{...}}. A jaw step is {stage, kind:'open' or 'close', side:'left' or 'right'}. Move arguments use native freespace_move keywords left/right_target_pos and left/right_target_rpy, planning_speed, and optional normalized left/right_gripper_target_width. Leave the idle arm fixed unless explicitly planned. Include approach, pickup, lift, transport, placement, release, withdrawal and returns. Account for both predicted arm endpoints and jaw states throughout.

The generic runtime fully plans the sequence before the first task command. Its controller owns queue admission, Home, the capability, paired 10 Hz packets, Stop and parking. No lease/controller API or unattended physical retry loop belongs in generated source. Live execution captures a fresh scene and replans; old poses and trajectory cache keys are reference evidence only. Native collision/joint-limit/planner failures remain failures. Do not invent calibration offsets or additional confidence/clearance cutoffs. The held object is not attached as a native collision body.

The current user task and observed scene determine source, target and arm choice. Historical task colors, pixel locations, orientations and coordinates do not override them. Reuse compatible published/local code and preserve each recipe's validation scope and unresolved caveats. FULL_PLAN_ONLY is planning evidence; completed API packets are not physical success.

evaluate receives fresh read-only tools and the task dictionary. Return {success: bool, evidence: {...}} from actual post-retreat images/depth; retain uncertainty. The runner separately reviews through parking. Save exact source and outcomes; local learning lives outside run outputs. After physical failure, review evidence and revise/replan rather than replaying a trial.
