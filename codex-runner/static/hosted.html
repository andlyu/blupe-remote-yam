    How to use the playground

    We built this playground to help people understand how well robotics actually works in the real world—and what it takes to make it work. It’s one thing to see a sped-up demo, and another to watch an arm complete a task.

    You can run LLMs online using an API key or pay through Stripe. For more flexibility, we recommend cloning the repository and running it locally with your Codex or Claude subscription. This makes it easier to experiment and change how the model interacts with the arms.

    We also encourage you to experiment with the robot API, customize how the LLM is used, or train your own models. We’ve collected five hours of block-moving and stacking demonstrations, and we’d love to see what you train with them.

    Task wise, we intentionally open it up as a playground with a variety of objects to see what people like to play with. However, if there is a specific task that you would like to try, we would love to set it up for you.

    Keys stay out of logs. Robot controls stay with your session.
